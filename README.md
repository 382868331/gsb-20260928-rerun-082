# 硬件逻辑分析工作站

支持从多路人工电平采样中解码 UART（8/9 数据位、none/even/odd/mark/space 校验、1/2 停止位、高低空闲极性可配置）和 SPI 风格时钟同步串行（位序 MSB/LSB、上升/下降采样边沿、片选通道与有效电平、每字位数可配置）。采样块、解码配置、结果版本分开保存；同一采样记录可用不同解码配置对照，修改配置会新增配置版本并生成独立结果，原结果保留可比较。

## 结构

- `backend/internal/model`：采样、配置、标记和结果模型。
- `backend/internal/decode`：协议注册表；`uart.go` 与 `spi.go` 是启用协议。新增协议时在 `registry.go` 注册。
- `backend/internal/store`：JSON 持久化存储，捕获、采样块、配置版本、结果、跨采样对齐互不覆盖。
- `backend/internal/alignment`：用户共同事件锚点、分段漂移映射、外推可信范围。
- `backend/internal/api`：HTTP API 与内置核对波形。
- `frontend/src/components/WaveformTrack.tsx`：轨道、标记、以鼠标时间点为锚点的缩放和平移。

## 解码语义

- 采样块按索引和时间戳拼接；UART 状态跨块保留，半个帧可在下一块继续。
- 块时间戳不连续且交叠在帧内时，输出 `sampling-gap`，丢弃未完成帧，不补造字节。
- 停止位错误、校验错误和超出容差的时钟边沿异常均输出独立错误标记，不产生正常字节。
- 字节和错误都有纳秒级 `startNs`/`endNs`，叠加在原始波形轨道上核对。
- SPI 在片选有效区间内按配置边沿采样数据位；片选中途结束或采集结束时输出 `incomplete-frame` 并保留原始位，不补全字节。
- 片选无效期间出现的采样时钟边沿输出 `clock-outside-cs` 错误标记。
- 结果列表中点击任一标记可将波形视口定位到该字节/错误的原始采样区间，缩放平移不影响定位。
- 再次载入内置示例（含刷新页面后）按采样名称复用同一采样身份：重开的是原采样上用户另存过的配置与结果对照，不会生成同名新示例。
- `POST /api/results/diff` 对照同一采样的两个解码结果，定位首个不同标记的波形区间，并按 `bit-order`（位序）、`clock-edge`（采样边沿）、`incomplete-frame`（片段不完整）说明差异根因；前端可从差异条目直接跳到对应波形区间。
- `POST /api/alignments` 使用若干用户确认的共同事件创建不可变跨采样对齐；响应包含分段偏移/漂移，保存采纳锚点和被排除的重复脉冲候选。
- `POST /api/results/cross-diff` 按既有对齐比较不同采样，不修改原采样或已保存解码版本；差异分为 `actual-signal`（实际信号不同）、`sampling-missing`（采样缺段）、`protocol-parameters`（协议参数不同），无法唯一对应的片段保留为 `unmatched`，并给出另一采样上的可信时间区间。
- 修改对齐依据会创建新的对齐 ID；旧报告引用旧 ID，重开后仍可追溯每个锚点及被排除候选。跨采样面板的结果选择按采样身份隔离，切换采样不会沿用另一份采样的配置。
- 跨采样面板列出全部已保存比较，点击即可按原对齐 ID 重开，恢复同一组采集段、锚点、被排除候选与差异解释（`GET /api/alignments`、`GET /api/alignments/{id}`）；刷新页面或重启服务后映射按持久化锚点重算，仍指向同一轮重复报文，不会跳入另一轮同名时间区间。

## 时钟重置与采集段

- 同一份逻辑采样在采集中途重置时钟（时间戳回绕、重新从较小值开始）时，解码器输出 `clock-reset` 边界标记并把后续块划入新采集段；每个标记携带 `segmentIndex`，重置前后的相同时间戳是不同事件。波形轨道把各采集段依次排开，段界以虚线标出。
- 跨采样对齐按采集段对（基准段 ↔ 另一段）分别建立分段映射，绝不把整份记录统一拉伸；没有锚点证据的段保持 `unmatched`，不借用其他段的映射。
- 跨采集段的先后关系与段内锚点共同约束候选：锚点按（采集段号, 段内时间）构成全局次序，较早段事件对到另一采样末尾、末段事件对到其开头的首尾逆序会被拒绝（409，`cross-segment-ordering`），冲突列出经过的两个锚点及所在段；自动匹配的重复报文候选若与任一锚点全局次序矛盾也被排除，方向上没有锚点证据时仍保留歧义，不强行匹配。
- 重复通信内容产生多个候选时保留歧义；可人工确认共同事件缩小候选。同一采集段对内锚点先后关系倒序会被拒绝（409），并指出冲突经过的锚点和段；修订与已保存对齐矛盾的锚点时，响应列出冲突（`contradicts-saved-alignment`），旧对齐决定保持不可变，修订另存为新对齐 ID，只重算依赖它的比较。
- 差异原因区分 `sampling-missing`（局部缺段）、`clock-drift`（内容一致但时间残差超出锚点不确定度）、`actual-signal`（真实协议内容变化）与 `protocol-parameters`（协议参数不同）。每条差异携带采集段号与所采用的对齐锚点 ID，保存重开后仍可回到原始采集段及对齐证据；从异常字节反查另一采样时，按段对定义域定位，跨段跳转不会进入错误的一轮同名时间区间。

## 运行

```bash
cd backend && go run ./cmd/server -addr :8080 -static ../frontend/dist -data data/logicstation.json
```

开发模式：

```bash
cd backend && go run ./cmd/server -addr :8080 -data data/logicstation.json
cd frontend && npm install && npm run dev
```

打开页面后会自动调用 `POST /api/demo` 生成内置核对波形。UART 波形包含有效字节以及跨块续接后发现的停止位异常；SPI 波形包含已知字节 0x48/0x69（跨块续接）、片选中途结束的不完整报文和片选无效期间的错误时钟边沿，并预置 MSB/LSB/错误边沿三组配置用于对照。额外的两份“跨采样人工波形”包含重复 A/B/A/C 脉冲、局部缺失块和分段漂移变化，预置四锚点及被排除的重复 A 候选。“跨采样人工波形 C（两次时钟重置）”在采集中途两次重置时钟，三个采集段各带重复 A 报文；“跨采样人工波形 D（对照无重置）”含一处真实字节差异（C→X）和末段漂移，预置每段一个 A 锚点用于核对跨段跳转。
